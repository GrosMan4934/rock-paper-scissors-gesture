# Камень, ножницы, бумага с распознаванием жестов

Интерактивная игра **«Камень, ножницы, бумага»**, в которой выбор игрока определяется с помощью жестов руки через веб-камеру.  
Программа распознаёт положение пальцев в реальном времени, определяет жест игрока, случайно выбирает ход компьютера и выводит результат раунда на экран.

## Описание проекта

Проект реализован на Python с использованием компьютерного зрения.  
В качестве источника изображения используется веб-камера, а для отслеживания руки применяется библиотека **MediaPipe Hands**.  
Программа анализирует координаты суставов пальцев, вычисляет углы сгиба и определяет, какой жест показал игрок:

- **Камень** — все пальцы согнуты;
- **Ножницы** — подняты указательный и средний пальцы;
- **Бумага** — подняты все пальцы;
- **?** — жест не распознан.

После короткого таймера компьютер делает случайный выбор, а программа определяет победителя по стандартным правилам игры.

## Возможности

- Распознавание руки через веб-камеру в реальном времени.
- Определение жестов «Камень», «Ножницы» и «Бумага».
- Использование углов суставов пальцев для проверки, согнут палец или нет.
- Сглаживание распознавания жестов с помощью буфера последних результатов.
- Таймер перед фиксацией выбора игрока.
- Случайный выбор хода компьютером.
- Автоматическое определение результата раунда.
- Отображение текста на русском языке поверх изображения с камеры.
- Автоматический запуск нового раунда.

## Используемые технологии

- Python
- OpenCV

## Управление

- Покажите жест рукой перед камерой.
- Дождитесь окончания таймера.
- После завершения выбора программа покажет ход игрока, ход компьютера и результат.
- Для выхода нажмите `Q`, `q` или `Esc`.

## Как работает программа

1. Камера считывает изображение.
2. Кадр зеркально отражается для удобства пользователя.
3. MediaPipe находит ключевые точки руки.
4. Для каждого пальца вычисляются углы в суставах.
5. По количеству разогнутых пальцев определяется жест.
6. Несколько последних распознаваний сохраняются в буфер, чтобы уменьшить ошибки.
7. После завершения таймера компьютер выбирает случайный жест.
8. Программа сравнивает выбор игрока и компьютера.
9. На экран выводится результат раунда.
